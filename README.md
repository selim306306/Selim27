# موقع مكتبة مدرسة الأمين (ب)

## محتويات المجلد
- `index.html` — الصفحة الرئيسية
- `periodicals.html` — الدوريات الشهرية (فيها العدد الأول + رابط تحميل PDF)
- `catalog.html` — فهرس الكتب (بيانات تجريبية — استبدلها ببياناتك)
- `news.html` — أخبار المكتبة (بيانات تجريبية — استبدلها بأخبارك)
- `contact.html` — تواصل معنا (النموذج شكلي حاليًا، محتاج ربط بخدمة خارجية)
- `alamin-periodical-issue-01.pdf` — ملف العدد الأول
- `assets/style.css` — التنسيق العام لكل الموقع
- `assets/nav.js` — قائمة الموبايل

## طريقة الرفع على GitHub Pages
1. انسخ كل الملفات والمجلدات دي **بنفس البنية** (متغيرش أسماء الملفات) داخل الريبو:
   `selim306306.github.io/selim/`
2. تأكد إن مجلد `assets` وملف الـ PDF اترفعوا في نفس المستوى (جنب `index.html`).
3. بعد الرفع، الموقع هيكون متاح على نفس الرابط الحالي.

## إيه اللي محتاج تعدّله بنفسك
1. **فهرس الكتب** (`catalog.html`): مصفوفة `books` في آخر الملف — كل كتاب سطر بصيغة:
   `{ title: "العنوان", author: "المؤلف", category: "التصنيف", status: "available" أو "out" }`
2. **أخبار المكتبة** (`news.html`): كل بطاقة خبر جوه `<div class="card news-card">` — انسخ نفس التنسيق لخبر جديد.
3. **تواصل معنا** (`contact.html`): غيّر البريد الإلكتروني في قسم "بيانات التواصل"،
   واربط النموذج بخدمة زي Formspree عشان الرسايل توصل فعليًا (حاليًا شكلي بس).
4. **الدوريات** (`periodicals.html`): لما يجهز العدد الثاني، انسخ بطاقة `issue-card`
   وحدّث بياناتها، وارفع ملف PDF جديد بنفس الطريقة.

## الحماية والإحصاءات
دول محتاجين خطوة تانية بعد ما توافق على شكل الموقع الحالي — راجع رسالة المحادثة لتفاصيل الخيارات المتاحة
(كلمة سر / تحليلات زيارات / حماية تقنية) لأن كل خيار له طريقة تنفيذ مختلفة على GitHub Pages.
